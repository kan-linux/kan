## How to fetch codes

```bash

git clone --recurse-submodules https://github.com/kan-linux/kan.git

```

## How to build

Ubuntu 26.04 is recommended as the host OS. Kan-Linux v0.3.0 will become the recommended host OS in the future.
 
```bash
make deps
make clean
make
```

If everything succeeds, you will get the LiveISO.

We will release the full build guidelines and the refined build system before 2027/01/01.
